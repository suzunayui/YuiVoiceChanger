# Apple Silicon Mac試用版

macOS 14以降・Apple Silicon（M1以降）向けです。現時点ではCPUで変換します。Intel MacとApple GPU（MPS）での推論、RVCモデルからの学習には対応していません。

1. DMGを開き、YuiVoiceChangerをApplicationsへコピーします。
2. アプリを開き、「環境設定」から必要な環境を自動セットアップします。Python 3.15.2と音声処理ライブラリを専用フォルダに準備します。システムのPythonやHomebrewは変更しません。
3. モデル一覧からBeatriceの.pt.gz／.pt、または.tomlと.bin一式を追加します。「つくよみちゃんで試す」も利用規約への同意後に使えます。
4. マイクと出力先を選び、声変換を開始します。初回はmacOSのマイクへのアクセスを許可してください。許可しなかった場合は「システム設定 → プライバシーとセキュリティ → マイク」で変更できます。

CPUの処理速度によって遅延が長くなります。最初は固定遅延をオフにして確認してください。目標が短すぎる場合は必要な最小値が表示されます。モデル、アイコン、プリセット、エフェクトはWindows版と同じ操作です。

配信・通話へ渡すには、BlackHoleなどの仮想オーディオデバイスを別途用意し、変換出力を仮想デバイスへ、OBSの声ソースをその入力へ設定します。仮想デバイスは同梱・自動インストールしません。

OBSプラグインと声・伴奏のミックスはWindowsで利用できます。

この試用版はApple Developer IDによる署名・公証を行っていません（ローカルのアドホック署名のみ）。初回にmacOSが起動を止めた場合は、アプリを開こうとした後に「システム設定 → プライバシーとセキュリティ」でこのアプリの起動を許可してください。

ビルドはGitHub ActionsのApple Silicon Mac上で行います。自動セットアップ、CPUの合成入力による推論、アプリ起動・Core Audioデバイス選択を確認します。実際のマイク・スピーカーを使った音質とOBS録画の同期測定は、自動テストの対象外です。
