# Beatriceの設定

アプリの「はじめての設定」に、ダウンロード先と準備手順があります。
未設定の初回起動では、このガイドが自動で表示されます。
公式VSTはダウンロード後、ZIPをすべて展開してください。
「展開したVSTフォルダを選ぶ」で、展開先のbeatrice_2.0.0-rc.3フォルダを指定できます。

Pythonを新しく用意する場合はWindows用Python 3.12（64bit）を使い、PowerShellで以下を実行します。

```powershell
py -3.12 -m pip install numpy sounddevice pedalboard==0.9.25
py -3.12 -c "import sys; print(sys.executable)"
```

2行目に表示されたpython.exeを環境設定で指定し、アプリを再起動してください。
通話用途ではVB-CABLE等を別途準備し、アプリの出力をCABLE Input、通話アプリのマイクをCABLE Outputに指定します。

公式Beatrice 2.0.0-rc.3 VST3を外部プラグインとしてホストします。
対応モデルは2.0.0-rc.0形式、声IDは0です。

1. https://prj-beatrice.com/ からWindows用VSTを取得して展開します。
2. Python 3.11以降に `pip install -r requirements.txt` で依存関係を入れます。
3. 環境設定でPythonとモデルの.tomlを選択します。
4. VSTは外側の.vst3フォルダのパスを入力するか、参照ボタンでその中の `Contents/x86_64-win/*.vst3` を選択します。
5. マイク・出力先・音高・ゲインを調整して変換を開始します。

処理ブロックは10・20・40msです。音切れが出る場合は長くしてください。
総遅延にはモデル内部と音声デバイスの遅延も加わります。
無音中のノイズ抑制で小声が消える場合は、しきい値を下げてください。
「声をクリアにする（軽いEQ）」は350Hz付近を2dB抑え、3.5kHz以上を2dB持ち上げます。
変換を停止してON/OFFを切り替え、同じフレーズで比較してください。
これは変換後の音色調整です。モデルの発音や学習内容そのものは変わりません。
音声変換はCPUで行います。Electronの画面描画ではGPUを使う場合があります。

設定のインポート・エクスポートは環境設定から行います。
別の場所に依存ライブラリを置く既存構成では、JSONの `beatrice_libs` も保存されます。
モデル・VST・Python・依存ライブラリは配布物に含みません。

## 歌唱モード（試用）

停止中に「歌唱モード」をONにすると、入力音高に応じて会話用の音高と＋0を自動で切り替えます。会話側は「音の高さ」の値（例：＋14）を使い、設定自体を書き換えません。OFFなら従来の固定補正です。

初期境界は300Hz。高音が80ms続くと歌唱側へ、境界の80%以下が180ms続くと会話側へ戻ります。音高は短いランプで変化し、歌唱側に入った後は無音や無声音が続いても維持し、低い声を検出したときだけ会話側へ戻ります。停止して再開した場合は会話側から始まります。しきい値は150〜900Hzで変更できます。

歌・会話の内容を認識する機能ではありません。低音の歌では会話側、高い話し声では歌唱側になる場合があります。切り替えでメロディの音程が変わることもあるので、実際の歌声でしきい値を調整してください。CPUだけで推定し、GPUや新しい学習モデルは不要です。
